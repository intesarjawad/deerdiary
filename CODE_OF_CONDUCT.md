# Code of conduct

Treat contributors with respect. Discuss ideas and code without personal attacks. Harassment, discrimination, threats, sexualized conduct, and disclosure of private information are unacceptable.

Maintainers may remove content or restrict participation to protect contributors. They should explain decisions privately where possible and apply these rules consistently.
