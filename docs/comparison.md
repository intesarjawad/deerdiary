# How Deerdiary compares

Checked on 2026-11-10 against each project's own pages. Each of these does something Deerdiary does not.

|                                                                           | What it is                                                                                          | What it asks of you                                                                                                                                                                                                                 | Where it is stronger                                                                                                            |
| ------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| [Wildlife Insights](https://wildlifeinsights.org/faq)                     | Cloud platform for camera trap data with automatic species identification                           | An account; only approved Data Contributors upload; ["All data submitted ... will be made publicly available unless it is embargoed"](https://wildlifeinsights.org/get-started/share-data/sharing-preferences), for up to 48 months | Shared projects, a public dataset, team workflows; free for most users, with fees expected from government and for-profit users |
| [AddaxAI](https://github.com/PetervanLunteren/AddaxAI)                    | Desktop app: detection, species recognition, verification, dashboards, exports (MIT)                | An install on Windows, macOS or Linux                                                                                                                                                                                               | Large batches on your own GPU, model choice, verification tools                                                                 |
| [Timelapse](https://timelapse.ucalgary.ca/)                               | Free desktop tool for coding images into your own data fields; works offline                        | An install                                                                                                                                                                                                                          | Custom data fields and a mature review workflow                                                                                 |
| [MegaDetector](https://microsoft.github.io/MegaDetector/)                 | The detector: boxes on animals, people and vehicles, "an animal detector, not a species classifier" | Python, or a hosted Space or notebook                                                                                                                                                                                               | The reference detector, many model sizes, and the project Deerdiary builds on                                                   |
| [SpeciesNet](https://github.com/google/cameratrapai)                      | Google's detector plus classifier ensemble, more than 2,000 labels (Apache-2.0)                     | `pip install speciesnet`                                                                                                                                                                                                            | The reference implementation Deerdiary ports; use it for official results                                                       |
| [TRAPPER](https://trapper-project.readthedocs.io/en/stable/overview.html) | Open-source Django web platform for camera trap projects, with an AI manager and Camtrap DP support | A server you run                                                                                                                                                                                                                    | Team projects, expert review and citizen science modules                                                                        |
| [camtrapR](https://cran.r-project.org/web/packages/camtrapR/index.html)   | R package: organise images, extract metadata, detection histories, occupancy models                 | R                                                                                                                                                                                                                                   | Everything after the diary: occupancy and spatial capture-recapture analysis                                                    |
| [Zamba Cloud](https://zamba-cloud.drivendata.org/)                        | Hosted web app for classifying animals in camera trap videos                                        | An account and an upload                                                                                                                                                                                                            | Video models for African and European species, and training on your own labelled data                                           |

Deerdiary does one thing in this list that the others do not: it reads a card with no install, no account and no upload. It does not replace a cellular camera's remote delivery, and it is not an analysis package.
